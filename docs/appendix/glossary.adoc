== Glossary

LSP::
Language Server Protocol.
A JSON-RPC-based protocol defined by Microsoft that standardizes communication between code editors (clients) and language analysis tools (servers).
LSP enables features like auto-completion, go-to-definition, diagnostics, and hover information across any editor that supports the protocol.

Tree-sitter::
A parsing library that generates parsers from grammar definitions.
The parsers produce concrete syntax trees (CSTs) and support error recovery and syntax-aware queries.

AsciiDoc::
A lightweight markup language for writing technical documentation, articles, books, and other prose content.
AsciiDoc documents can be converted to HTML, PDF, EPUB, and other formats using processors like Asciidoctor.

arc42::
A template for documenting software architecture, created by Gernot Starke and Peter Hruschka.
The template defines 12 sections.
It is available in AsciiDoc, Markdown, and other formats.

CST::
Concrete Syntax Tree.
A parse tree that represents the complete syntactic structure of a source document, including all tokens, whitespace, and punctuation.
Unlike an AST (Abstract Syntax Tree), a CST preserves enough information to reconstruct the original source text exactly.

AST::
Abstract Syntax Tree.
A simplified tree representation of a source document's structure that omits syntactically insignificant details like whitespace and delimiters.
ASTs are commonly used in compilers and code analysis tools where the exact source layout is not important.
