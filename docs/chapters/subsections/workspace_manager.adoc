= Workspace Manager

[[workspace]]
The Workspace Manager holds the extracted data of all documents in the workspace and the relationships between them, primarily include directives.

On `initialized`, the server scans the workspace root for AsciiDoc files and then calculates and publishes the diagnostics.
The scan runs on a thread of its own, so the server keeps answering requests and ends on `exit` while it runs; until the scan is done, there is no workspace:

[source,rust]
----
include::{lsp-source-dir}/main.rs[tags=workspace-setup]
----

`textDocument/didOpen`, `didChange`, and `didSave` re-parse only the affected file.
Before the scan has finished, they parse nothing; the installed workspace takes the content of the open buffers.
File watchers pick up external changes to AsciiDoc and `.asciidoctorconfig` files.
After a change, the diagnostics are recalculated.

Includes form a directed graph.
A circular include is detected and reported as a diagnostic on the offending include directive.
A top-level document is derived from the graph: it is a document that no other document includes.
