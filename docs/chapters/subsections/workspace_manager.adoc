=== Workspace Manager

[[workspace]]
The Workspace Manager is the central stateful component of asciidoc-lsp.
It maintains an up-to-date representation of all documents in the workspace, their parsed syntax trees, and the relationships between them (primarily through include directives).

When the server starts, the Workspace Manager initializes by scanning the workspace root directory for AsciiDoc files.
It builds an initial include graph by parsing the top-level documents and following their include directives recursively.
This initial scan is performed asynchronously to avoid blocking the LSP initialization handshake.

As the user edits documents, the Workspace Manager receives `textDocument/didChange` notifications and incrementally updates the affected syntax trees.
Treesitter's incremental parsing is essential here: instead of re-parsing the entire document on every keystroke, only the changed region and its syntactic dependencies are re-parsed.
This keeps update latency well below the 200ms responsiveness target even for large documents.

The Workspace Manager also tracks document dependencies.
When a file that is included by other documents changes, the manager invalidates the cached analysis for all dependent documents.
This ensures that diagnostics and navigation features always reflect the current state of the workspace, even when edits in one file affect the semantics of another.

The include graph is represented as a directed acyclic graph (DAG), with cycle detection to handle the edge case of circular includes gracefully.
When a cycle is detected, the manager emits a diagnostic on the offending include directive and breaks the cycle to prevent infinite recursion during analysis.
